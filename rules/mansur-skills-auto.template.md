# Skills во всех проектах без ручного вызова

До задачи прочитай `~/.gemini/config/skill-inventory.json` и выбери установленные skills по реальной задаче и их description. Для кода/сайта/логики автоматически применяй mansur-frontend-mentor и project-coding-rules; для React — vercel-react-best-practices в пределах выбранного стека; для screenshot/браузерной проверки — agent-browser; для сложных фаз — подходящие GSD skills. При простой задаче не запускай полный GSD workflow.

Не ожидай /skill или имени skill от пользователя. Область — любой новый/существующий workspace, файл и branch. Каталог показывает доступность, а не доказанное runtime чтение.

Не запускай все skills одновременно. Не интерпретируй автоприменение как разрешение commit/push, delete, reset, отправки сообщений или изменения аккаунтов. Эти действия требуют подходящей команды пользователя. Соблюдай системные инструкции и текущий запрос; сохраняй чужие настройки и исходную логику.
